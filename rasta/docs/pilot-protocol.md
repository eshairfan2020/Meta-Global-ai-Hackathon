# Mini pilot protocol (3–5 people, ~10 minutes each)

Purpose: see whether people can reach an *independent* verification step without help. This is a tiny, informal pilot —
report it as observations, never as proof that Rasta prevents fraud or saves money.

**Consent first.** Tell each person it is a prototype, all messages are fictional, they can stop any time, and you will
record only what is written below (no names needed; use P1, P2…).

**Setup.** Phone-sized browser, Rasta running, synthetic examples only. Two groups if you have ≥4 people:
- Group A sees the full flow (assessment + family verification).
- Group B sees only the assessment screen (risk banner, quotes, safe reply) — then is asked what they would do.

**Tasks (don't help unless they are stuck > 1 minute; note where they got stuck).**
1. “You received this message. Use Rasta to decide what to do.” (family example)
2. “What would you do next, before sending any money?”
3. “Does Rasta say the request is definitely a scam / definitely safe?” (checks understanding of uncertainty)
4. “Where would you find the incident record?”

**Record per person (P#):** language preferred · completed unaided (Y/N) · first action chosen (call known number /
ask another relative / send money / other) · understood Rasta can't block payment (Y/N) · understood “insufficient evidence” ≠ safe (Y/N) · quote or comment.

**Report honestly:** number of people, how recruited, what you changed afterwards, and that n is tiny.
