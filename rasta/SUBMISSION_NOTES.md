# Submission notes — Rasta (Meta Global AI Developer Hackathon, Indie track, Cerebral Valley)

Accurate model statement: *This project uses Meta Llama through Ollama on the developer's local Windows machine.
Demonstration inputs are synthetic. In Ollama mode, assessments are generated by the running model. Mock mode uses
predefined results and is labeled separately.*


## What genuinely works (verified by automated tests)
- Backend API, schema validation, input limits, redaction, quote/amount verification, in-memory cases, verification
  timeline, HTML incident export, delete — 44 backend tests pass.
- Ollama adapter (`POST /api/chat`, JSON-schema `format`, low temperature, one retry on invalid JSON, timeout / unreachable /
  model-missing / busy handling) — **verified against mocked HTTP responses only**.
- No silent fallback: Ollama failures return technical errors, never a mock or "insufficient evidence" assessment.
- React UI flows (examples, mock analyze, edit-invalidates, failure state, copy, verification, export, delete, language toggle)
  — 4 jsdom tests against a stubbed backend; production build succeeds.

## What is synthetic
- All four demo inputs (family emergency, verification-code request, legitimate-looking request, ambiguous urgency).
  They contain no real people, numbers, accounts or CNICs, and are labeled “Synthetic example — not a real incident.”

## What is mocked
- `AI_PROVIDER=mock` returns predefined fixtures for the four examples (English and Roman Urdu), labeled
  “Predefined sample assessment”. These are not model output and must not be shown as inference results.
- Unit tests mock the Ollama HTTP layer.

## What remains untested
- **Live inference with a real Meta Llama model**: output validity rate, latency on the Ryzen 5 PRO 3400G, memory use.
- Whether a 1B/3B model flags the verification-code example reliably (risk of false reassurance), and Roman Urdu quality.
- Real-browser behaviour (mobile layout at ~375 px, print dialog / Save as PDF), Windows PowerShell setup steps.
- No usability testing with real users; no accuracy, demand, or loss-prevention claims are made.

## What is deferred or not implemented
- Firebase Auth/Firestore (optional; not implemented), screenshots/OCR, voice, deepfake detection, automatic alerts,
  trusted-contact enrollment, bank integrations, link fetching, authority complaints, other models.
- No deterministic rules layer (e.g. flagging an explicit code request independent of the model); a possible small
  safety addition if live tests show the model missing such cases.

## Caveats
- Meeting the "every runtime model is Meta" requirement does not guarantee acceptance, scoring, or a prize. Re-check the
  official Cerebral Valley submission rules, video length and deadlines yourself.
- Do not use “world's first”, “guaranteed protection”, or any invented accuracy figures in the pitch.
